# Numpad MacroPad

Numpad MacroPad перетворює NumPad ноутбука на повноцінний багатошаровий макропад з overlay та зручним GUI-налаштуванням. Проєкт написаний для AutoHotkey v2 та працює одразу після запуску.

## Структура проєкту
```
/NumpadMacroPad
├─ main.ahk
├─ gui.ahk
├─ overlay.ahk
├─ config.json
└─ README.md
```

## Як запустити
1. Встановіть [AutoHotkey v2](https://www.autohotkey.com/).
2. Склонуйте або завантажте цю папку.
3. Запустіть `main.ahk`. Після старту відкриється вікно **Settings** і додасться іконка в системний трей.

## Керування
- **NumPad 0–9** — виконує призначені дії активного layer.
- **NumpadAdd (+)** — наступний layer.
- **NumpadSub (−)** — попередній layer.
- **Утримання NumpadDot (.) або NumpadDel** — показує напівпрозорий overlay з назвою layer та підписами кнопок; overlay зникає після відпускання.
- **Tray → Settings** — відкрити GUI налаштувань.
- **Tray → Numbers Mode** — переключити NumPad між цифрами та макро-режимом.
- **Tray → Exit** — повністю завершити роботу програми.

## Налаштування через GUI
- Панель **Layers** дозволяє додавати, видаляти та перейменовувати слої.
- Таблиця для кнопок Numpad 0–9 містить **Button Label**, **Action Type** (Send Key, Send Text, Run Program), **Action Value** та кнопку **Record** для запису комбінації клавіш.
- Усі зміни автоматично зберігаються в `config.json`. Якщо файл відсутній або пошкоджений, він буде пересозданий з дефолтними значеннями.

## Overlay
- Напівпрозоре вікно без рамок, AlwaysOnTop, не перехоплює фокус.
- Показується під час утримання `NumpadDot`/`NumpadDel` та коротко після перемикання layer (+/−).

## Numbers Mode
Опціональний режим, в якому NumPad поводиться як звичайні цифрові клавіші. Перемикається через трей.
